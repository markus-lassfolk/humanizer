# Danish references

- `da-frequencies.json` — log-odds weights, generated by `locales/nordic/scripts/build-wordlist.mjs`.
- Human baseline: public texts from CFCS, DR, Datatilsynet, Digst, FE (190 texts / 168k words). **Not committed** — rebuild it with `locales/nordic/scripts/fetch-human-baseline.mjs`.
- Model baseline: ~60 synthetic LLM-default-style texts (Claude only, no API key spent). Run other models for a broader sample.
- Report: `locales/nordic/reports/baseline-da.md`.

Regenerate:

```bash
node locales/nordic/scripts/build-wordlist.mjs da <humanDir> <aiDir> locales/da-dk/references/da-frequencies.json
node locales/nordic/scripts/baseline-report.mjs da <humanDir>
```
