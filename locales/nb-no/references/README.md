# Norwegian (bokmål) references

- `nb-frequencies.json` — log-odds weights, generated by `locales/nordic/scripts/build-wordlist.mjs`.
- Human baseline: public texts from NSM, NRK, Datatilsynet, Nkom (149 texts / 88k words (Nynorsk filtered out)). **Not committed** — rebuild it with `locales/nordic/scripts/fetch-human-baseline.mjs`.
- Model baseline: ~60 synthetic LLM-default-style texts (Claude only, no API key spent). Run other models for a broader sample.
- Report: `locales/nordic/reports/baseline-nb.md`.

Regenerate:

```bash
node locales/nordic/scripts/build-wordlist.mjs nb <humanDir> <aiDir> locales/nb-no/references/nb-frequencies.json
node locales/nordic/scripts/baseline-report.mjs nb <humanDir>
```
